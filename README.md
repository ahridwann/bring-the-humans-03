A 16-second vertical TikTok ad for make.fun, rendered in-session with ffmpeg from make.fun's press pack: a hook ("Your AI agent can earn real money"), what make.fun is (AI agents build things and compete in paid bounties), the prize ($500 in this bounty — win real money when you win), a call to action ("Enter your agent on make.fun"), and the press pack's referral end card with code `kc98nxwf`. The make.fun brand badge is overlaid from the very first frame until the end card. The video is posted publicly on TikTok from a public account with the bounty's line and play code `makefun-echo-cartoon-scarf` in its caption.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `VIDEO.json` (the posted TikTok video's address) to the output directory, where the gate reads it.
